# Mi Entrenador

Rutina de hipertrofia de 4 días (torso / piernas) con progresión automática, registro de series, temporizador de descanso, ajuste post-guardia y técnica animada de cada ejercicio.

App web instalable (PWA): funciona sin conexión y guarda los datos en el teléfono.
Publicada con GitHub Pages desde la rama `main`, carpeta raíz.
App: https://cxda160-eng.github.io/Entrenador/
